## Common use cases
{: #common-use-cases}

You can implement the following common patterns by using {{site.data.keyword.messagehub}}:

Real-time stream processing
:   Process high-velocity event streams as they occur by integrating with stream-processing engines such as Kafka Streams and ksqlDB.

Asynchronous microservices communication
:   Decouple microservices by publishing events to topics, allowing independent services to consume and act on messages at their own pace.

Event sourcing and audit logging
:   Capture state changes as an immutable sequence of events to provide durable audit history and enable replay of business events.

Data pipeline integration
:   Ingest data from diverse cloud and on-premises sources into analytical data stores and databases by using Kafka Connect.
